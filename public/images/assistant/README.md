# ZHINO — دستیار ژینو (تصویر ربات)

## فایل

| File                   | Role                                          |
| ---------------------- | --------------------------------------------- |
| `zhino-assistant.png`  | تصویر اختصاصی ربات «دستیار ژینو» — ۳۲۰×۳۲۰، پس‌زمینهٔ شفاف (RGBA) |

## منبع و شفافیت

- این فایل **عکس واقعی نیست**: یک تصویرسازی ساخته‌شده با مدل تولید تصویر است
  (پرامپت: ربات دستیار سفارشی/لوکس با کلاهک ژله‌ای، پالت burgundy `#71313B`،
  `#2A0B12`، ivory `#FAF7F2` و طلایی مات `#B89A62`).
- پس‌زمینه به‌صورت ماسک‌گذاری روی کانال آلفا حذف شده (بدون هالهٔ تیره در لبه‌ها)،
  سپس برش «سر + سینه» گرفته شده تا در اندازهٔ کوچک (۴۴px روی دکمهٔ شناور) هم
  واضح و قابل تشخیص بماند.
- هیچ‌کدام از عکس‌های واقعی محصولات و دسرهای ژینو (`products/`, `showcase/`,
  `IMG_20260903_*`) در این تصویر دست‌کاری نشده‌اند و این فایل هرگز به‌عنوان
  عکس واقعی محصول به کار نمی‌رود.

## استفاده

| محل                                             | کامپوننت                                        |
| ----------------------------------------------- | ----------------------------------------------- |
| دکمهٔ شناور (همهٔ صفحه‌های فروشگاه)               | `src/components/assistant/ZhinoAssistant.tsx`   |
| صفحهٔ مستقل `/assistant` (سربرگ + محیط گفتگو)     | `src/pages/AssistantPage.tsx`                   |
| آواتار ربات (سربرگ گفتگو و پیام‌ها)               | `src/components/assistant/AssistantAvatar.tsx`  |

- همهٔ این‌ها از یک کامپوننت مشترک (`AssistantAvatar`) استفاده می‌کنند و
  مسیر تصویر در `src/components/assistant/assistantData.ts` یک‌جا تعریف شده است.
- آدرس تصویر با `withSiteBase()` ساخته می‌شود، پس روی دامنهٔ اصلی (`/`) و روی
  مسیر مخزن (`/zheno-website/`) هر دو درست بارگذاری می‌شود.
- اگر فایل به هر دلیلی نباشد، کامپوننت به‌جای تصویر شکسته یک نشانهٔ برداری
  درون‌خطی از همان ربات نشان می‌دهد.

## جایگزینی

برای تغییر چهرهٔ ربات، کافی است همین فایل با یک PNG ۳۲۰×۳۲۰ شفاف جایگزین شود؛
هیچ کد دیگری نیاز به تغییر ندارد (هویت بصری دکمه، سربرگ و پیام‌ها از همین یک
فایل می‌آید).
