# ZHINO — دستیار ژینو (تصویر واقعی ربات)

## فایل

| File             | Role                                                            |
| ---------------- | --------------------------------------------------------------- |
| `بارگیری.jpeg`   | تصویر واقعی ربات «دستیار ژینو» — 1024x1536 (نسبت 2:3)، JPEG |

- این فایل **همان تصویر اصلی و دست‌نخوردهٔ ربات** است؛ بدون بازطراحی،
  فیلتر، تغییر رنگ یا برش.
- پوشهٔ `concepts/` فقط طرح‌های اولیهٔ پیشین را نگه می‌دارد و در سایت
  استفاده نمی‌شود (`concept-A-v3.jpg` همان بایت‌به‌بایت همین فایل است).

## استفاده

| محل                                             | کامپوننت                                        |
| ----------------------------------------------- | ----------------------------------------------- |
| دکمهٔ شناور (همهٔ صفحه‌های فروشگاه)               | `src/components/assistant/ZhinoAssistant.tsx`   |
| صفحهٔ مستقل `/assistant` (سربرگ + خوش‌آمدگویی)    | `src/pages/AssistantPage.tsx` / `ZhinoWelcomeAnimation.tsx` |
| صحنهٔ استودیو (ربات قهرمان صحنه)                  | `src/components/assistant/ZhinoLoungeScene.tsx` |
| آواتار ربات (سربرگ گفتگو و پیام‌ها)               | `src/components/assistant/AssistantAvatar.tsx`  |

- همهٔ این‌ها از یک آدرس مشترک (`ASSISTANT_BOT_IMAGE` در
  `src/components/assistant/assistantData.ts`) استفاده می‌کنند.
- آدرس تصویر با `withSiteBase()` ساخته می‌شود، پس روی دامنهٔ اصلی (`/`) و
  روی مسیر مخزن (`/zheno-website/`) هر دو درست بارگذاری می‌شود.
- تصویر همه‌جا با نسبت اصلی و `object-fit: contain` (یا
  `preserveAspectRatio` در SVG) نمایش داده می‌شود — نه کشیده می‌شود و نه
  بریده؛ و هیچ انیمیشن، پلک‌زدن یا افکتی روی آن اعمال نمی‌شود.
