# ZHINO — image assets

The home Hero uses only the real uploaded product photos that already live in
`public/images/products/`.

No generated dessert imagery is used for the Hero. Product files must remain
untouched: no crop, edit, redraw, retouch, recolor, re-encode, or distortion.
If a product photo needs a different shape, the website frame must adapt to the
original file dimensions.

## Product photography

Per-product photos live in `products/` — see `products/README.md`. Their filenames
were historically matched from uploaded files, so the flavor name printed inside
each photo is the ground truth.
